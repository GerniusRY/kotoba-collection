# ことばコレクション（試作版）

## 起動

このフォルダで `python3 -m http.server 8000` を実行し、Chrome / Safari で `http://localhost:8000` を開きます。iPhoneで使う場合はHTTPS対応の静的ホスティング（GitHub Pages等）へ `index.html` `style.css` `app.js` を配置してください。ローカルネットワークのHTTPアクセスではiPhoneのマイクが利用できないことがあります。

1. 「マイクをはじめる」を押し、マイク利用を許可します。
2. 「りんご」「くるま」「いちご」「みかん」「き」「たいよう」は手続き型3Dで表示します。
3. その他の名詞は日本語版Wikipediaの画像検索を行います。画像がない場合は単語・絵文字表示になります。
4. 「⚙」から親子しりとり（やさしい／対戦）を選べます。
5. 「ずかん」でブラウザ内に保存された収集履歴を確認できます。
6. 音声が利用できない場合は「ことばを入力」でテストできます。

## 技術・制約

- Three.jsをCDNから読み込むため、初回起動にはインターネット接続が必要です。
- 音声認識はブラウザのWeb Speech APIに依存します。iOS Safariでの継続動作は保証できません。非対応時は手入力にフォールバックします。
- Wikipedia画像検索は通信状況、検索結果、ライセンス条件に左右されます。取得画像はアプリに再配布せず、外部URLを表示します。実運用前に画像の権利・出典表示を整備してください。
- 収集図鑑はlocalStorageに保存します。サイトデータ削除時には消去されます。
- 3Dは手続き型の試作モデルで、フォトリアル品質ではありません。高品質な実物3Dはライセンス確認済みGLBモデルへの差し替えが必要です。
- しりとりの長音処理は簡易実装です。音声認識は名詞抽出をせず、発話全体を単語として扱います。語尾の判定や不明瞭な幼児発話への補正は追加開発が必要です。
- テレビ音声の回り込み防止は読み上げ中の認識停止で簡易対応しています。
